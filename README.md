# Python To-Do List App

A beginner-friendly command-line task manager built with Python. Tasks are saved locally in a JSON file, so they remain available after the program closes.

## Features
- View all tasks
- Add a task
- Mark a task as complete
- Delete a task
- Save tasks automatically in `tasks.json`
- Validate menu choices and task numbers

## Requirements
- Python 3.9 or newer
- No external packages required

## How to run
1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python main.py
   ```

   On some systems, use `python3 main.py`.

## Project structure
```text
python-todo-list/
├── main.py
├── README.md
└── .gitignore
```

`tasks.json` is created automatically when you save your first task.

## Skills demonstrated
Python functions, loops, conditionals, exception handling, JSON serialization, and file handling.
